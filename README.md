## কেন ডাক্তার বাড়ি?

হাসপাতালের ওয়েবসাইটগুলো ইংরেজিতে, তথ্য ছড়িয়ে-ছিটিয়ে, আর ফোন নম্বর খুঁজে পাওয়া কঠিন — বিশেষ করে বয়স্ক রোগীদের জন্য। ডাক্তার বাড়ি এই সমস্যার সহজ সমাধান: **জেলা → এলাকা → রোগের ধরণ** — মাত্র ৩ ধাপে সঠিক ডাক্তার, বড় বড় অক্ষরে, এক ট্যাপে ফোন।

| | |
|---|---|
| **ডাক্তার** | ৯৫+ তালিকাভুক্ত, প্রতিদিন বাড়ছে |
| **ক্যাটাগরি** | ২১টি বিশেষজ্ঞ বিভাগ |
| **সিরিয়াল** | এক ট্যাপে সরাসরি ফোন |
| **ভাষা** | সম্পূর্ণ বাংলা ইন্টারফেস |

## কী কী পাবেন

- **৩-ধাপে খোঁজ** — জেলা, তারপর এলাকা, তারপর রোগের ধরণ। কোনো টাইপিং লাগে না, শুধু বড় বাটনে চাপ দিন।
- **সকল ডাক্তার, এক পাতায়** — ক্যাটাগরি অনুযায়ী সাজানো গ্রিড; যেমন হৃদরোগের সব ডাক্তার একসাথে।
- **প্রোফাইল পেজ** — ছবি, চেম্বার ঠিকানা, রোগী দেখার সময়, ভিজিট ফি, আর বিশাল **ফোন করুন** বাটন।
- **কমিউনিটি যাচাই** — নম্বর সঠিক হলে "হ্যাঁ, নম্বর সঠিক" চাপুন; ভুল হলে সঠিক নম্বর পাঠিয়ে দিন। সবাই মিলে তথ্য হালনাগাদ রাখে।
- **ভালো-খারাপ মতামত** — উপকারী / ভুল তথ্য / রিপোর্ট — স্বচ্ছ, সবার চোখের সামনে।
- **নিজের তথ্য যুক্ত করুন** — ডাক্তার বা রোগী, যে কেউ ফর্ম পূরণ করে তথ্য পাঠাতে পারেন; যাচাইয়ের পর লাইভ হয়।

## তথ্য কতটা বিশ্বাসযোগ্য?

প্রতিটি তালিকায় অবস্থা স্পষ্ট লেখা থাকে:

| ব্যাজ | অর্থ |
|---|---|
| যাচাইকৃত (BMDC নম্বরসহ) | রেজিস্ট্রেশন নম্বর দেওয়া, অগ্রাধিকারযোগ্য |
| Verifying | সংগৃহীত তথ্য, ফোনে নিশ্চিত হওয়া বাকি — সিরিয়ালের আগে যাচাই করে নিন |
| ✓ N জন নিশ্চিত করেছে | সাধারণ ব্যবহারকারীরা নম্বরটি ঠিক বলেছেন |

> জরুরি অবস্থায় সবসময় নিকটস্থ হাসপাতাল বা **৯৯৯**-এ যোগাযোগ করুন।

## ঘুরে দেখুন

| পাতা | কী আছে |
